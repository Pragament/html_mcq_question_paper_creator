Build a completely NEW, independent web application based on the functionality of the existing MCQ Question Paper Creator.

APPLICATION NAME:
School MCQ Paper Studio

IMPORTANT:
This is a NEW application. Do not simply copy broken code from an existing application.

Recreate the functionality, workflows, UI behavior, editing capabilities, import/export capabilities, question management, equation tools, Mermaid tools, table tools, paper management, and AI workflow described below.

The new application must be modular, maintainable, responsive, and designed so that multiple AI models/providers can be added without changing the core application.

Do NOT remove or simplify any feature listed below.
